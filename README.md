# inf-campus-grade-hider
Hides grades on Infinite Campus until they are clicked on by the user. This does not hide the grades shown in the grades tab; however, it does hide the ones on the dashboard and in the notifications list.

# Installation
1. Install a userscript manager like [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) (Chrome) or [Greasemonkey](https://addons.mozilla.org/en-US/firefox/addon/greasemonkey/) (Firefox).
2. Click [here](https://github.com/kamishiro-624/inf-campus-grade-hider/raw/refs/heads/master/script.user.js) to access the userscript. Click the install button when prompted.
3. Reload the website to make sure the script executes correctly.
